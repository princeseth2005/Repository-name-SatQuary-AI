ISRO / SIH26167 — SatQuery AI Project Overview

Problem Statement

SatQuery AI: An Interactive Vision-Language Assistant for Multimodal Remote Sensing Image Analysis through Text Queries (SIH26167, Space Technology Theme).

The Core Challenge

Conventional satellite image interpretation requires complex GIS software (e.g. QGIS, ArcGIS, ERDAS Imagine) and specialized remote sensing training. Decision makers in agriculture, disaster response, and urban development cannot easily converse with spatial imagery.

SatQuery AI Solution

An end-to-end interactive vision-language system that bridges high-resolution optical imagery, computer-vision spectral indices (VARI, NDWI, Laplacian texture variance), and natural-language reasoning. Users upload any satellite raster and ask conversational questions to receive quantitative metrics, spatial masks, and formal reports.

Key Features:
  • Optical multi-spectral estimation (VARI, GLI, NDWI-RGB)
  • Dual-image temporal change detection (CIE-Lab & Sobel diff)
  • Interactive multi-layer mask overlays with alpha blending
  • Leaflet geospatial location & GeoTIFF support
  • Self-contained offline CV reasoning engine
  • Instant downloadable PDF analysis briefs
ISRO Standard Disclaimer:

Algorithmic estimates on 3-band RGB imagery are mathematical approximations. For mission-critical cadastral surveys, calibrated multispectral L2A bands (Sentinel-2, Landsat-9, or Cartosat/Resourcesat) should be integrated.
